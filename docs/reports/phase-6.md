# Отчёт: Фаза 6 — Промпт-интеллект и бонусы

Дата: 2026-10-02. Локальный SillyTavern 1.19.0 (Docker), NAI Studio 0.6.0, серверный плагин 0.3.0, NovelAI Opus. Основной API для LLM — NovelAI Erato (текстовый). Все генерации бесплатные: баланс до и после проверок одинаковый (9241 Anlas).

## Критерии приёмки

| Критерий | Результат | Как проверено |
| --- | --- | --- |
| Русский промпт даёт осмысленный английский результат, повторный перевод берётся из кэша | ✅ | Вживую через Erato: «рыжая девушка в школьной форме, улыбка, 1.2::сакура::» → «1girl, red hair, school uniform, smile, 1.2::sakura blossom petals::» (6 с), повтор — из кэша за 0,17 с. Автоперевод: «кот спит на подоконнике, солнечный свет» → «cat, sleeping, window, sun», картинка сгенерирована, русский оригинал в метаданных (`sourcePrompt`) — и при ручном переводе тоже. Путь Chat Completion со схемой JSON — тестами (локально нет Chat Completion) |
| Счётчик токенов не расходится с реальным отказом NovelAI по длине | ✅ по решению П-12 | NovelAI длинный промпт не отвергает (RECON c15), поэтому сверка — с токенайзерами и лимитами веб-клиента. Мои Qwen / T5 / CLIP против эталона Hugging Face `tokenizers` на 12 промптах (веса, диакритика, пустая строка, длинный текст): 36 из 36 совпадений; тест на настоящих файлах есть в наборе (включается переменной `NAIST_TOKENIZER_DIR`). В панели считаются ровно строки payload: V4.5 33 / 512, V5 37 / 1471 (текст в кадре — 1), V3 35 / 225 для одного и того же промпта |
| Сгенерированный набор эмоций подхватывается Expressions без ручного переименования | ✅ | Полный набор для Lyra: 28 из 28 спрайтов за 230 с (основа, 16 эмоций Director, 11 img2img), загружены в `characters/Lyra/`. `GET /api/sprites/get?name=Lyra` возвращает все 28 меток Expressions. Персонаж одинаковый во всех спрайтах (скриншот-мозаика); радость и грусть у Director «emotion» выражены сдержанно |
| Экспорт и импорт настроек на чистой установке восстанавливает рабочее состояние полностью | ✅ | Тест «чистой установки»: экспорт с промптом, стилем, позой, глоссарием и картинкой вайба → импорт даёт те же настройки и картинку в IndexedDB; старая схема мигрирует, более новая отклоняется. Вживую через UI: импорт изменённого файла (с подтверждением и резервной копией) и обратный импорт исходного — настройки совпали побайтно |

## Что сделано

- **Перевод RU → EN** текущим LLM: кнопка «RU → EN» у каждого поля промпта с кириллицей, автоперевод перед генерацией (персонажи тоже), `/nai-translate`.
  - Chat Completion — `generateRaw` со схемой JSON; текстовые API — few-shot-продолжение (П-53).
  - Глоссарий «русский = english» на вкладке «Промпты»; кэш в IndexedDB; блоки `text:` не переводятся.
- **Подсказки тегов** во всех полях промпта панели, композера и паспорта:
  - 20 000 тегов Danbooru с частотностью, категориями и алиасами, ~400 русских алиасов (П-52);
  - подсказки NovelAI через плагин;
  - Enter / Tab — вставка, ↑/↓ — выбор, Esc — закрыть;
  - строка «неизвестные теги».
- **Веса**: Ctrl+↑/↓ меняют вес тега под курсором (`1.05::тег::` на V4+, скобки на V3); при переходе на V3 числовые веса переводятся в скобки, невыразимое удаляется с сообщением (П-54).
- **Счётчик токенов** под полями: промпт (база + персонажи на V4+) и нежелательное до лимита модели, текст в кадре V5 отдельно, предупреждение T5 о кириллице и эмодзи, «≈» без файла токенайзера (П-51).
- **Текст в кадре V5 (autoText)** как на сайте NovelAI — фразы в кавычках идут в блок `teXt:` (П-50), с переключателем.
- **Function tool** `GenerateImage`: аргументы кто в кадре, действие, настроение, план, место; с персонажами — сцена из паспортов; Anlas-гард и cooldown (П-55).
- **Спрайты эмоций** для Expressions: диалог (`/nai-sprites`, пункт «Ещё…» карточки, вкладка «Картинки»), режимы «основа + Director» и «один сид», прозрачность на V5, выбор меток (включая свои метки Expressions), прогресс, загрузка в папку персонажа (П-56).
- **Комикс V5** (`/nai-comic`): 7 раскладок, страница, поля, стиль, промпт и реплики на панель с отдельным счётом токенов текста, сборка страницы (П-57).
- **Непрерывность сцены**: локации в метаданных чата, img2img от картинки локации или вайб, автопривязка новых картинок, распознавание локации в тексте, `/nai-location` (П-58).
- **Экспорт и импорт** всех настроек одним JSON (П-59).
- **Плагин 0.3.0**: файлы токенайзеров (белый список, дисковый кэш) и подсказки тегов (П-60).
- Схема настроек v6.

## Найдено и исправлено при проверке

- Erato не выполняет JSON-инструкцию: ST оборачивает строку для NovelAI в `{ … }` с префиксом имени пользователя, и модель отвечала рассуждением о переводе. Теперь — системное сообщение, few-shot, prefill «English:», первая строка; ответы-рассуждения отбраковываются.
- Неудачный ответ попадал в кэш переводов — теперь кэш проверяется при чтении, плохие записи удаляются.
- Теги качества NovelAI (masterpiece, best quality…) помечались как неизвестные — добавлены в индекс; две цели русских алиасов поправлены на имена Danbooru.
- autoText перед тегами качества давал «,,» — перенесён после них.
- В подсказке про веса фигурные скобки читались как плейсхолдер локализации.

## Что не проверено вживую и почему

| Что | Почему | Чем закрыто |
| --- | --- | --- |
| Перевод со структурированным выводом (Chat Completion) | Локально основной API — NovelAI (текстовый) | Тест: `jsonSchema` передаётся, ответ читается |
| Function tool | Tools уходят к модели только на Chat Completion с function calling | Тесты аргументов; путь генерации общий с панелью и сценой |
| Непрерывность в режиме вайба | Кодирование V4/V4.5 стоит 2 Anlas | Использует библиотеку вайбов Фазы 5 и её проверки |
