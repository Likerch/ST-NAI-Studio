# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Версии по фазам ТЗ (`phase-0` … `phase-6`) и следующим этапам (`phase-7`).

## [0.9.3] — 2026-10-03

### Исправлено

- Совместимость с Qvink Memory и другими расширениями, которые убирают сообщения из промпта: сообщения с картинками больше не возвращаются в промпт целиком. Перехватчик заменял их копией через `structuredClone`, а она теряет пометку SillyTavern «не включать в промпт» (`extra[symbols.ignore]`); теперь копия поверхностная.

## [0.9.2] — 2026-10-02

### Добавлено

- Кнопка **«Аватар по паспорту»** в панели персоны: бесплатный портрет по паспорту персоны (без NSFW-слоя, по-русски написанные слоты переводятся в теги), превью с кнопками «Поставить аватаром» / «Ещё вариант» / «Отмена», затем обрезка как при обычной загрузке аватара SillyTavern и замена файла персоны. Если паспорт пуст — открывается его редактор.

## [0.9.1] — 2026-10-02

### Добавлено

- Выбор vision-API и модели для мультимодальных режимов («ты», «лицо», «я») на вкладке «Чат»: OpenRouter, OpenAI, Anthropic, Google, Mistral, Groq, xAI, Cohere — с пометкой, сохранён ли ключ в SillyTavern. Выбор подставляется в Image Captioning только на время запроса.

### Исправлено

- «OpenAI API key is not set» в мультимодальном режиме, когда в Image Captioning выбран API без ключа: теперь можно выбрать API с ключом, а если описание всё же не удалось — картинка делается по описанию модели чата (обычный режим) с одним предупреждением.

## [0.9.0] — 2026-10-02

Полная интеграция с Doom's Enhancement Suite.

### Добавлено

- Интеграция с DES (вкладка «Чат» → «Doom's Enhancement Suite»), включается сама, если DES установлен:
  - сцена из трекера во всех картинках: время суток, погода, помещение / улица, локация (паспорт-локация и непрерывность); в режимах separate / external картинки ждут трекер;
  - персонажи трекера в картинках с текущим обликом поверх паспорта, в том числе NPC без карточки;
  - паспорта для новых персонажей: поиск в карточках чата, иначе генерация по трекеру и сохранение в карточку; паспорт становится «Portrait prompt» DES;
  - портреты DES рисует NAI Studio (автопортреты DES на это время выключены): нет портрета / сменился облик / каждый ответ, постоянный сид на персонажа;
  - эмоции других персонажей карточки — в `characters/<имя>`, где их ищет DES;
  - пункты NAI Studio в меню портретов DES, «Проиллюстрировать» на баннерах сцены, кнопка паспорта в Workshop, «Паспорта для персонажей трекера».
- Макрос `{{nai_characters}}` включает персонажей трекера.
- Настройки v8 (`des`).

### Исправлено

- Картинки в пузырях чата DES не загружались (DES копирует элементы через `outerHTML`).
- Тихий `/sd` не открывает окно правки промпта и инспектор.
- Метка без персонажей не берёт слоты персонажей с панели генерации.

## [0.8.1] — 2026-10-02

### Исправлено

- Совместимость с Doom's Enhancement Suite (режим together): JSON метки картинки был для DES вторым объектом в ответе, и DES терял инфобокс и квесты этого сообщения. Обработчик меток теперь первый в `MESSAGE_RECEIVED` (`makeFirst`, место возвращается перед каждой генерацией) — DES видит уже плейсхолдер.

## [0.8.0] — 2026-10-02

Паспорта: несколько на карточку, виды, генерация по описанию, кнопки.

### Добавлено

- Несколько паспортов в карточке: каждый описанный персонаж, а также мир, локации, сценарий и предметы (их визуальные теги). Старый одиночный паспорт читается как основной персонаж.
- Кнопка «Паспорта» в карточке: менеджер паспортов (добавить, изменить, удалить, «Сгенерировать по описанию» — добавить новые или заменить все).
- Кнопка «Эмоции» в карточке и у каждого персонажа: спрайты Expressions по очереди; другой персонаж карточки — в свою подпапку (`/costume`).
- Паспорт персоны: кнопка в панели персон и «Заполнить по описанию» персоны.
- Метки картинок подхватывают персонажей с паспортом по имени в описании, в том числе по-русски и в падежах; теги мира, сценария и названных локаций добавляются к сцене. Макрос `{{nai_characters}}`.
- Серверный плагин 0.4.1: лимит ответа `/text` 4096 токенов.

### Исправлено

- Блок «генерируется / ошибка» метки получал класс композера `naist-marker` (кружок 26×26 с абсолютной позицией) — теперь свой класс.
- Теги паспортов больше не переписываются конвертером человеческого языка; исправление опечаток не заменяет короткие слова другими тегами (`stocky` → `stocks`).

## [0.7.1] — 2026-10-02

### Исправлено

## [phase-7] — 2026-10-02

Картинки по меткам в ответах модели и человеческий язык во всём расширении.

### Добавлено

- **Метки картинок в ответах** модели чата (вкладка «Чат»):
  - форматы `<img data-nai='{…}'>` (с `<figure>`/`<figcaption>`), URL старого микросервиса, sillyimages, Auto Illustrator;
  - все параметры метки: описание, нежелательное, персонажи по имени с позицией, позой и действием (паспорта внешности), пропорции, размер, модель, стиль, текст в кадре, сид, шаги, guidance, rescale, сэмплер, пресеты качества и UC, Variety+, прозрачность, локация, прошлая картинка как основа, вайб по имени, число вариантов, подпись, спойлер, выравнивание, ширина;
  - генерация начинается во время стриминга, как только метка дописана; очередь по одной;
  - ожидающие картинки с прогрессом, ошибкой и кнопкой «Повторить», в том числе после смены чата и в неактивных свайпах;
  - инструкция для модели в промпте: пресеты «обычный язык», «теги», «свой текст», число картинок в ответе (по умолчанию 1–3), глубина и роль, язык подписей, предпросмотр;
  - совместимость с HTML-виджетами на regex-скриптах: картинки приходят к ним как `<img>`;
  - иллюстрация ответа без меток (по желанию), платные картинки только с разрешением и лимитом.
- **Человеческий язык** (вкладка «Промпты»): описания по-русски и по-английски превращаются в промпт под выбранную модель перед каждой генерацией (сцена, персонажи, негатив); бэкенды — модель чата, профиль подключения, текстовая модель NovelAI; режимы авто / всегда / выкл; поле «Проверить»; кнопка «→ Промпт» у полей; `/nai-prompt`.
- Серверный плагин 0.4.0: `/text` — текстовые модели NovelAI (GLM-4.6, Xialong) для конвертера, без Anlas.
- README на английском и русском (`README.md`, `README.ru.md`).
- Исследование меток и человеческого языка — `docs/research/text-markers-and-natural-language.md`.
- Схема настроек v7 (`markers`, `language`, `inline.regexCompat`); «автоперевод» переходит в режим человеческого языка.

### Изменено

- Перевод RU → EN перед генерацией заменён конвертером человеческого языка; `/nai-translate` остался как простой перевод.

### Исправлено

- Три варианта удаления фона (`masked`, `generated`, `blend`) подписаны в метаданных свайпов, а не выглядят дублями.

### Проверено

- Платные проверки Фазы 5 вживую (с разрешения пользователя): вайб — 2 Anlas за первое кодирование и 0 при повторе, апскейл ×2 — 1, удаление фона — 65; прогноз совпал во всех случаях.
