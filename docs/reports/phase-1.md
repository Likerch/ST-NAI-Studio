## Расхождения с ТЗ

- Транспорта через CORS-прокси нет (решение П-3).
- ZIP на клиенте не распаковывается: плагин получает от NovelAI JSON, встроенный эндпоинт отдаёт base64 (решение П-4).
- Плагин отвечает 502 с настоящим статусом NovelAI внутри JSON вместо проброса статуса. Причина: ответ 401 сбросил бы Basic-учётки браузера на сервере с `basicAuthMode`.
- Модель по умолчанию — V4.5 Full: для Opus она бесплатна без лимита.
