# NAI Studio

[English](README.md) · **Русский**

Студия изображений NovelAI для [SillyTavern](https://github.com/SillyTavern/SillyTavern). Заменяет встроенное Image Generation клиентом, сделанным специально под NovelAI: все модели от V3 до V5, мультиперсонажные сцены с позициями, Director Tools, инпейнт, вайбы, живое превью, Anlas-гард, картинки, которые модель чата просит прямо в своих ответах, промпты обычным русским или английским языком — и при этом не ломает привычные команды, скрипты и сценарии.

|                  |                                                |
| ---------------- | ---------------------------------------------- |
| SillyTavern      | 1.19.0 и новее                                 |
| Подписка NovelAI | любая; бесплатные генерации считаются для Opus |
| Интерфейс        | русский, английский                            |
| Серверный плагин | по желанию, рекомендуется (0.4.1)              |
| Лицензия         | AGPL-3.0                                       |

## Зачем

Встроенное Image Generation видит в NovelAI один бэкенд из многих. NAI Studio построен вокруг того, что NovelAI умеет на самом деле:

- **Настоящий запрос.** Payload собирается так же, как на сайте NovelAI (теги качества, пресеты нежелательного, `v4_prompt`, промпты персонажей), и ничего, что модель не поддерживает, не отправляется. Инспектор показывает итоговый JSON до отправки.
- **Anlas под контролем.** Цена считается до каждого запроса, режим «только бесплатные» включён по умолчанию и не даёт потратить Anlas случайно, платные инструменты всегда спрашивают.
- **Токен остаётся на сервере.** Ключ NovelAI хранится в секретах SillyTavern (или в конфиге плагина) и никогда не попадает в браузер.

## Возможности

### Генерация

- Модели: V5 Full / Curated, V4.5 Full / Curated, V4 Full / Curated, Anime V3, Furry V3 — у каждой своя матрица возможностей (размеры, сэмплеры, расписания, SMEA, Variety+, прозрачность, предел персонажей).
- Мультиперсонажные промпты: у каждого свой промпт и нежелательное, позиции на сетке 5 × 5 (V4.x) или свободные (V5, до 32 персонажей).
- Сэмплер, расписание, guidance, rescale, сид, шаги, пресеты размеров, теги качества и пресеты нежелательного.
- **Живое превью** шагов денойзинга, пока картинка рисуется (с плагином); без него — оценка прогресса. Отмена действительно прерывает запрос.
- Инспектор payload и ручная правка JSON для экспериментов.

### В чате

- Все режимы встроенного (персонаж, лицо, пользователь, сцена, последнее сообщение, фон, свободный, мультимодальные), шаблоны промптов, общий префикс и суффикс, стили, промпты персонажей.
- `/nai`, а после замены встроенного — `/sd`, `/imagine`, `/img`, `/image` со всеми аргументами; пункт в меню-палочке, кнопка у сообщения, пункты в меню персонажа, интерактивный режим, макросы `{{charPrefix}}`.
- **Картинки внутри сообщений:** вставка по курсору, перегенерация, вариации, перетаскивание между сообщениями, подписи и спойлеры, сетка и карусель, режим чтения.
- Лайтбокс со всеми параметрами; сделать фоном чата или аватаром персонажа; сохранить PNG с метаданными NovelAI.
- Галерея всех генераций: поиск, фильтры, избранное, сравнение.
- PNG/WebP из NovelAI, брошенный на панель, загружает свои параметры.
- Автогенерация по правилам (каждые N сообщений, ключевые слова, смена сцены) с обязательным cooldown; в режиме «только бесплатные» Anlas не тратит никогда.
- Инструмент `GenerateImage` для LLM со структурированными аргументами: кто в кадре, действие, настроение, план, место.

### Картинки в ответах модели чата

- Модель чата пишет метку там, где уместна картинка, — `<img data-nai='{"prompt": "...", "caption": "..."}'>` — и на её месте появляется картинка. Инструкция добавляется в промпт сама (описания обычным языком или тегами, либо ваш текст), число картинок в ответе настраивается.
- **Генерация начинается ещё во время стриминга ответа**, как только метка дописана; генерации идут по одной.
- Все параметры метки: описание, нежелательное, персонажи по имени (их паспорта внешности, позиция, поза, действие), пропорции и размер, модель, стиль, текст в кадре, сид, шаги, guidance, rescale, сэмплер, пресеты качества и UC, Variety+, прозрачность, локация, прошлая картинка как основа (`ref`), вайб по имени, число вариантов, подпись, спойлер, выравнивание, ширина.
- Понимаются и старые форматы: URL картинок собственного микросервиса генерации, метки sillyimages и Auto Illustrator.
- HTML-виджеты на regex-скриптах продолжают работать: каждая картинка приходит к ним как `<img>`.
- По умолчанию только бесплатно; платные картинки по меткам — только с вашего разрешения и с лимитом цены. Неудавшуюся или прерванную картинку можно сгенерировать заново одним кликом.

### Персонажи и сцены

- **Паспорта** в карточке персонажа: база, волосы, глаза, тело, наряды, состояния, личное нежелательное, поза и позиция по умолчанию. У карточки их может быть несколько: **каждый описанный в ней персонаж**, а также **мир, локации, сценарий или предметы** (их визуальные теги) — ведь карточка не всегда один человек.
- **Кнопка «Паспорта»** в карточке и **«Сгенерировать по описанию»**: языковая модель читает описание, личность, сценарий и первое сообщение и пишет паспорта, вы их проверяете. У персон свой паспорт (кнопка в панели персон), заполняется по описанию персоны.
- Паспорта работают везде: в композере, автосцене, инструменте для LLM и **метках картинок в ответах** — персонаж, названный в метке (даже по-русски и в любом падеже), получает свою внешность сам; теги мира и сценария добавляются к каждой сцене чата, локация — когда её называют. Макрос `{{nai_characters}}` перечисляет персонажей с паспортом для ваших промптов.
- Библиотека поз (38), парные позы (объятие, за руку, на руках…) через теги взаимодействия NovelAI `source#` / `target#` / `mutual#`, кадрирование, ракурс, дистанция.
- **Композер сцены** с холстом позиций; автосборка по последнему сообщению: кто в кадре, позы и взаимодействия, счётчики персонажей. Работает в групповых чатах.

### Инструменты (на любой картинке в чате)

- **Director Tools:** лайнарт, скетч, раскраска, эмоция (24 эмоции), очистка, очистка с сохранением баблов, удаление фона. Результат — новым свайпом, оригинал не теряется.
- **Инпейнт и аутпейнт** в редакторе маски: кисть, ластик, инверсия, сохранение оригинала вне маски; V5 Curated честно перерисовывает через инпейнт V4.5 Curated.
- **Апскейл ×2** и **Enhance** (увеличение + img2img с силой и шумом).
- **Библиотека вайбов:** референсы, наборы с привязкой к персонажу, чату или стилю, сила и извлечение у каждого вайба. Кодировки кэшируются в браузере и на диске плагина — повторное использование вайба Anlas не стоит.

### Помощь с промптом

- **Человеческий язык везде:** опишите картинку по-русски или по-английски — в панели, композере, метках, где угодно — и перед генерацией описание станет тегами (и короткими фразами для V4.5 / V5) под выбранную модель. Преобразует ваша модель чата, отдельный профиль подключения или текстовая модель самой NovelAI (GLM-4.6, входит в подписку, Anlas не тратит); теги сверяются со списком Danbooru, глоссарий держит имена единообразными, результаты кэшируются, оригинал остаётся в метаданных картинки. Кнопка «→ Промпт» преобразует поле вручную.
- **Подсказки тегов** при вводе: 20 000 самых частых тегов Danbooru с частотностью и алиасами, ~400 русских алиасов, подсказки самого NovelAI; предупреждение о неизвестных тегах.
- **Веса** по Ctrl + ↑ / Ctrl + ↓ в синтаксисе модели (`1.05::тег::` на V4+, `{тег}` / `[тег]` на V3); при переходе на V3 числовые веса переводятся в скобки.
- **Счётчик токенов** на токенайзерах самого NovelAI (Qwen для V5, T5 для V4.x, CLIP для V3) с лимитами сайта; текст в кадре V5 — отдельно; предупреждение о символах, которые T5 не читает.

### Бонусы

- **Генератор спрайтов Expressions** (кнопка «Эмоции» в карточке): полный набор эмоций (28 меток) по очереди для встроенного Expressions, персонаж один и тот же, файлы называются и кладутся туда, где их ищет Expressions; другой персонаж карточки получает свою папку (переключение через `/costume`).
- **Страницы комикса** для V5: раскладки, промпт и реплики на каждую панель, страница собирается сама.
- **Непрерывность сцены:** последняя картинка локации становится основой (img2img) или вайбом следующей.
- Экспорт и импорт всех настроек одним JSON-файлом.

## Установка

1. **Расширение:** SillyTavern → Extensions → Install extension → `https://github.com/Likerch/ST-NAI-Studio`.
2. **Токен NovelAI:** API Connections → NovelAI → вставить постоянный API-токен (`pst-…`). Плагин читает его из секретов SillyTavern.
3. **Серверный плагин (рекомендуется):**
   - скопировать плагин: `install-server.ps1 -SillyTavern "C:\path\to\SillyTavern"` (Windows) или `./install-server.sh /path/to/SillyTavern` (Linux, macOS, Docker-хост);
   - включить плагины: `enableServerPlugins: true` в `config.yaml` (или env `SILLYTAVERN_ENABLESERVERPLUGINS=true`);
   - перезапустить SillyTavern. В панели появится «Серверный плагин 0.4.1».

Подробности, заметки про Docker и удаление — [docs/DEPLOY.md](docs/DEPLOY.md).

## Быстрый старт

1. Откройте **Extensions → NAI Studio**. Режим «только бесплатные» включён: Anlas не потратится.
2. Выберите модель, напишите промпт (теги или просто опишите картинку по-русски или по-английски), нажмите **Сгенерировать** — картинка придёт в чат.
3. Попробуйте в чате `/nai a cat on a windowsill, sunlight` или меню-палочку → NAI Studio.
4. На вкладке **Картинки** — библиотека вайбов, спрайты, комикс и непрерывность сцены; на вкладке **Промпты** — стили, настройки человеческого языка и помощь с промптом.
5. Чтобы модель чата иллюстрировала свои ответы: вкладка **Чат** → «Метки картинок в ответах» → включить. Инструкция добавится в промпт автоматически.
6. Когда будете готовы отказаться от встроенного: вкладка **Замена встроенного** → настройки переносятся автоматически при первом запуске → «Отключить встроенное и перезагрузить». Вернуть его можно в любой момент.

## Команды

| Команда                                                    | Что делает                                                                       |
| ---------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `/nai [промпт]` (`/nai-imagine`)                           | Сгенерировать картинку; принимает аргументы встроенного `/sd` и свои для NovelAI |
| `/imagine`, `/sd`, `/img`, `/image`                        | То же — после замены встроенного                                                 |
| `/nai-style [имя]` (`/imagine-style` после замены)         | Выбрать стиль или вернуть текущий                                                |
| `/nai-insert message=<id> [at=<позиция>] [промпт]`         | Сгенерировать и вставить картинку внутрь сообщения                               |
| `/nai-images`                                              | Показать или скрыть инлайн-картинки чата; режим чтения                           |
| `/nai-gallery`                                             | Открыть галерею                                                                  |
| `/nai-scene [edit=false] [target=message\|inline] [текст]` | Собрать сцену по последнему сообщению (или тексту)                               |
| `/nai-vibes`                                               | Открыть библиотеку вайбов                                                        |
| `/nai-prompt [текст]`                                      | Превратить описание по-русски или по-английски в промпт NovelAI для модели       |
| `/nai-translate [текст]`                                   | Перевести русский промпт в английские теги                                       |
| `/nai-sprites`                                             | Открыть генератор спрайтов Expressions                                           |
| `/nai-comic`                                               | Открыть конструктор комикса (V5)                                                 |
| `/nai-location [имя]`                                      | Задать или вернуть текущую локацию для непрерывности сцены                       |

## Приватность и безопасность

- Токен NovelAI не попадает в браузер и не хранится в настройках расширения.
- Сетевые запросы идут только в NovelAI (и на ваш сервер SillyTavern). Список тегов поставляется с расширением; файлы токенайзеров скачиваются с novelai.net один раз и кэшируются.
- Платные действия (кодирование вайба, апскейл, удаление фона, всё сверх бесплатных лимитов) всегда показывают цену и спрашивают подтверждение; режим «только бесплатные» блокирует их полностью.
- Преобразование человеческого языка использует выбранный вами LLM (модель чата, профиль подключения, настроенный в SillyTavern, или NovelAI через плагин); больше никуда ничего не отправляется.

## Разработка

```bash
npm ci
npm run build        # dist/index.js + dist/style.css (dist коммитится)
npm test             # vitest
npm run coverage     # покрытие слоя domain, порог 90%
npm run lint         # ESLint, включая границы слоёв
npm run format:check # Prettier
npm run deploy:local # копия в локальный SillyTavern
```

Слои: `ui` / `integration` → `features` → `domain` / `transport` / `core` → `shared`. Слой `domain` чистый и тестируется без DOM, сети и SillyTavern. Всё, что известно об API SillyTavern и NovelAI, с источниками — в [docs/RECON.md](docs/RECON.md); соответствие встроенному — [docs/PARITY.md](docs/PARITY.md); отчёты по фазам — [docs/reports/](docs/reports/); история — [CHANGELOG.md](CHANGELOG.md).
