# Отчёт: Фаза 2 — Паритет и замена встроенного расширения

Дата: 2026-10-02. Локальный SillyTavern 1.19.0 (Docker), NAI Studio 0.2.0, серверный плагин 0.1.0, аккаунт NovelAI Opus. Для LLM-режимов локальный ST переключён на текстовый API NovelAI (Erato), у Opus он не тратит Anlas.

## Критерии приёмки

| Критерий | Результат | Как проверено |
| --- | --- | --- |
| В `docs/PARITY.md` нет ни одной незакрытой строки | ⚠️ одна строка 🔒 | Все функции инвентаря RECON §2.1 закрыты: ✅, «✅ код» с причиной или N/A с причиной. Открыт только апскейл (`hr_scale`, `/sd scale=`): ТЗ относит его к Фазе 5. Нужно решение, см. ниже |
| После миграции пользователь видит свои старые стили, префиксы и персональные промпты | ✅ | Во встроенном локального ST заданы стиль Watercolor, промпт персонажа, function tool, интерактивный режим и `hr_scale` 1.5. Отчёт после перезагрузки: стиль перенесён; промпт персонажа «оставлен как в NAI Studio» (там уже был свой); переключатели перенесены; «только бесплатные» сохранён; апскейл помечен. Стоковые префикс и негатив пропущены. Переносы и отказы покрыты 14 тестами |
| `/sd` и `/imagine` выполняет NAI Studio, встроенное отключено, ошибок о дублях нет | ✅ | После «Отключить встроенное и перезагрузить»: `/sd`, `/img`, `/image`, `/sd-style`, `/sd-source` ведут в NAI Studio. `GenerateImage` зарегистрирован, `{{charPrefix}}` отдаёт промпт персонажа. В консоли нет ошибок и предупреждений. «Вернуть встроенное» возвращает `/sd` встроенному, тоже без ошибок |
| Автогенерация ни при каких настройках не тратит Anlas в режиме «только бесплатные» | ✅ | Бюджет автогенерации — `autoBudget(freeOnly, allowPaid)`: 0 при «только бесплатные» и без явного разрешения платных (тест на все 4 сочетания). В «только бесплатные» запрос и так урезается до бесплатного (фаза 1). Вживую: «только бесплатные» выключен, `allowPaid=false`, 29 шагов → «auto generation skipped: would cost 20 Anlas (budget 0)». Страничная заглушка `fetch` не поймала ни одного запроса генерации. Бесплатная автогенерация сработала: режим 4, стоимость 0 |

## Что проверено вживую

Всё бесплатно: метаданные каждой картинки — стоимость 0. Баланс до и после контрольной генерации — 9305 → 9305.

- `/nai` в свободном режиме, `/nai quiet=true`, `char,` с промптом персонажа (1:1 и группа).
- LLM-режимы `you`, `face`, `last`, `background` и `extend=true`; окно правки (`edit=true`, правленый промпт ушёл в генерацию).
- Фон: альбомный 1344×704, урезан до ≤ 1 МП, фон чата установлен через `FORCE_SET_BACKGROUND`.
- Интерактивный режим: «Please draw a picture of yourself» → картинка вместо ответа LLM.
- Кнопка у сообщения: на картинке — новый свайп с другим seed; на тексте — картинка прикрепляется к сообщению, текст остаётся.
- Overswipe вправо на последней картинке → новая генерация.
- Меню-палочка и пункты меню карточки («лицо» → `generation_type` 5, «портрет» → 0).
- `/sd-style` (поля панели обновились), `/sd-source comfy` → `novel` с подсказкой.
- Группа: имя «SillyTavern System», папка — id группы, `{{char}}` в тексте подставлен.
- Вкладки панели, баннер, отчёт миграции, замена встроенного туда и обратно.

Вживую не проверялись (в PARITY отмечены «✅ код»):

- мультимодальные режимы — в локальном ST нет мультимодального источника подписей;
- вызов `GenerateImage` моделью — у текстового API NovelAI нет tool calling, а без него ST инструменты не вызывает. Регистрация проверена;
- реакция на смену ключа NovelAI — секреты локального ST не трогал.

## Найдено и исправлено при проверке

- Миграция принимала стоковые значения нового пользователя ST за правки (П-26).
- В группах сообщение-результат подписывалось пустым именем, а `{{char}}` в тексте был пустым. Теперь системное имя, как во встроенном (П-27).
- Служебные токены Erato `<|…>` с `|` ломали сегменты промпта NovelAI (П-29).
- Карточки, импортированные после миграции, теряли промпт `sd_character_prompt`. Теперь он читается как запасной источник; чужое поле не пишется.
- После `/sd-style` и миграции поля панели показывали старые значения.
- Ошибка интерактивной генерации уходила только в консоль, теперь показывается тост. У автогенерации тихо пропускаются только срабатывания ограничителя Anlas.
- Пропуск автогенерации по бюджету запускал паузу, как будто картинка была.
- Не было стилей для вкладок, баннера и выпадающего меню палочки.

## Расхождения с ТЗ (внесены в RECON §5)

- **П-26.** `default/content/settings.json` даёт новому пользователю старые дефолты: префикс с `masterpiece`, шаблоны режимов 2 и 7. Миграция считает их дефолтами.
- **П-27.** В ST 1.19 позиционная форма `substituteParams(content, name1, name2)` переопределение имени игнорирует. Используется `substituteParamsExtended`.
- **П-28.** После интерактивной картинки Regenerate снова рисует: перехватчик видит чат без системных сообщений. Встроенное ведёт себя так же, оставлено ради паритета.
- **П-29.** Удаление `<|…>` из ответов LLM — отличие от встроенного в лучшую сторону.
- **П-30.** Апскейл: встроенное его поддерживает для NovelAI, ТЗ относит его к Фазе 5. Нужно решение.

## Отложено

- Апскейл — по решению П-30.
- Инлайн-картинки и галерея — Фаза 3; позы и сцены — Фаза 4; вайбы, Director Tools, инпейнт, стрим — Фаза 5; аргументы инструмента «кто в кадре, настроение, план» — Фаза 6.
- Установка на рабочий сервер — после всех фаз.

## Состояние локального окружения

- Встроенное Image Generation снова включено. NAI Studio: «только бесплатные» включён, автогенерация выключена. Тестовые стили удалены, тестовые изменения настроек встроенного откачены.
- Основной API локального ST переключён с Horde на текстовый NovelAI (Erato): он нужен для LLM-режимов.
- Остались тестовые данные: группа «NAIST test group» и картинки в чатах Seraphina и группы. Сам их не удалял — безвозвратное удаление делаю только по вашему решению.

## Наблюдение

Баланс Anlas с конца Фазы 1 снизился 9339 → 9305 без платных запросов из этой сессии: все генерации здесь бесплатные, контрольная генерация баланс не изменила. Тем же аккаунтом NovelAI пользуются и другие клиенты.
