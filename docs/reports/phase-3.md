# Отчёт: Фаза 3 — Инлайн-изображения и галерея

Дата: 2026-10-02. Локальный SillyTavern 1.19.0 (Docker), NAI Studio 0.3.0, серверный плагин 0.1.0, NovelAI Opus. Все генерации фазы бесплатные: у каждой картинки в метаданных стоимость 0.

## Критерии приёмки

| Критерий | Результат | Как проверено |
| --- | --- | --- |
| Редактирование текста сообщения не ломает ни одну картинку | ✅ | Штатный редактор ST: правка до, после и вокруг метки, новая строка в конце. Картинка и все её 3 варианта на месте. Плюс тесты `reconcile` |
| Удаление сообщения освобождает его блобы в IndexedDB | ✅ | Тестовое сообщение с картинкой → `/cut`: ключ блоба исчез из IndexedDB, счётчик блобов 4 → 3. Удаление варианта и картинки освобождает свои блобы, а варианты в других свайпах сообщения остаются |
| Чат с 200 картинками прокручивается без просадок | ✅ | Сообщение с 200 картинками: монтирование 106 мс, сразу загружено 6, на каждом шаге прокрутки ещё ~10 (только у экрана), задержка цикла событий не больше 6 мс |
| Перетащенный PNG из веб-клиента NovelAI заполняет параметры корректно | ✅ | Вживую: файл NovelAI (WebP с EXIF), перетащенный на панель, заполнил 18 полей. Тесты на настоящих метаданных NovelAI: PNG (tEXt, как у веб-клиента) и WebP с двумя персонажами — промпт без тегов качества, пресет UC, модель по `Source`, персонажи со своими UC и координатами |
| Экспорт чата средствами ST сохраняет картинки | ✅ | `/api/chats/export` (jsonl) содержит `extra.nai_images` с путями `/user/images/…`, файлы доступны. Если копии в браузере нет (другое устройство), картинка рендерится из файла (проверено на 200 картинках без копии в браузере) |

## Что сделано

- **Модель хранения.** В тексте `[nai:img:<uuid>]`, картинки в `extra.nai_images[]` (П-31). Файл в `/user/images` и копия в IndexedDB по умолчанию (П-32).
- **Рендер.** Хук `messageFormatter` + проход по текстовым узлам для системных сообщений (П-33). Ленивая загрузка (П-34).
- **Вставка.** Кнопка у сообщения (после выделенного текста или в конец), кнопка в режиме правки (по курсору), `/nai-insert message= at=`. Режимы: свой промпт, «по тексту» (промпт пишет LLM), все триггеры встроенного. Несколько картинок в одном сообщении.
- **Отображение.** Ширина в % или px, выравнивание, обтекание, подпись, alt, рамка, скругление, спойлер. Несколько подряд — сетка, карусель или список.
- **Действия над картинкой.** Варианты со стрелками и счётчиком «2/4», перегенерация на месте, вариация (тот же сид + шум, img2img через плагин), «переделать с правкой промпта», удаление варианта, перетаскивание внутри сообщения и между сообщениями.
- **Лайтбокс.** Все параметры (промпт, сид, модель, размер, шаги, guidance, сэмплер, пресеты, персонажи, стоимость, время). Действия: копировать промпт и сид, фон чата, аватар персонажа (с подтверждением), сохранить на диск в PNG с метаданными NovelAI. Реестр действий для Director Tools и инпейнта из фазы 5.
- **Массовые действия.** Скрыть или показать картинки чата, режим чтения без картинок (палочка, вкладка «Картинки», `/nai-images`).
- **Согласование.** После правки, свайпа, регенерации и удаления: записи без метки и метки без записи убираются, неиспользуемые блобы чата удаляются. Свайпы сообщения хранят свои копии `extra`, поэтому их картинки не трогаются (проверено вживую).
- **LLM.** Метки не уходят в промпт: вместо них `[image: подпись или промпт]` или ничего. Чат при этом не меняется.
- **Галерея.** Все генерации с превью и параметрами; поиск по промпту, тегам, сиду, персонажу; фильтры по модели, персонажу, чату и датам; избранное; сравнение двух рядом с подсветкой отличий; «повторить с изменением»; массовое удаление (по желанию вместе с файлами на сервере); объём хранилища браузера.
- **PNG.** Импорт параметров перетаскиванием на панель или кнопкой. Сохранение на диск в формате NovelAI. Переключатель «вычищать метаданные» действует на сервер и на диск.
- **Настройки** — вкладка «Картинки», схема v3.

## Найдено и исправлено при проверке

- Перегенерация и вариация добавляли промпт персонажа, которого не было у исходной картинки: сохранённая сцена шла по правилу свайпа медиа. Флаги разделены.
- `requestAnimationFrame` не срабатывает в неотрисованном окне, монтирование не происходило. Переход на `setTimeout`.
- Ленивая загрузка в скрытом окне не загружала ничего (П-34).
- Перетаскивание PNG на панель видел и обработчик ST («Unsupported file type»). Всплытие остановлено.
- `escapeHtml` не экранировал кавычки в атрибутах. Исправлено.

## Расхождения с ТЗ (RECON §5)

П-31 (варианты — объекты), П-32 (файл и копия в браузере по умолчанию), П-33 (системные сообщения без хука), П-34 (ленивая загрузка с опросом), П-35 (метка видна в режиме правки).

## Отложено

- Отправка в Director Tools и инпейнт из лайтбокса — фаза 5 (место под действия готово).
- Data Maid может считать файлы инлайн-картинок бесхозными (RECON §2.3 п. 9). Копия в браузере их сохраняет, а «Сохранить на диск» и фон чата заново создают файл при необходимости.
