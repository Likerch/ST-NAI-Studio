## [phase-5] — 2026-10-02

Продвинутые возможности NovelAI.

### Добавлено

- Серверный плагин 0.2.0:
  - `/generate-stream` (SSE без буферизации, отмена при отключении браузера);
  - `/encode-vibe`, `/encode-vibe/lookup` с дисковым LRU-кэшем кодировок (`vibeCacheMb`);
  - `/augment` (Director Tools), `/upscale`;
  - установочные скрипты сохраняют `config.json` и кэш.
- `domain`: тела запросов Director Tools, 24 эмоции, размеры как в веб-клиенте, геометрия аутпейнта, размеры Enhance и апскейла, планирование вайбов (до 16) и статус доступности по модели и транспорту.
- `transport`: разбор SSE, кадры прогресса, маршруты Фазы 5 у плагина, функции по версии плагина.
- Инструменты на любой картинке чата (медиа сообщения, инлайн-картинки, лайтбокс):
  - Director Tools — 7 инструментов;
  - инпейнт и аутпейнт в редакторе маски;
  - апскейл ×2;
  - Enhance;
  - результат — новым вариантом той же картинки.
- Библиотека вайбов: референсы, наборы с привязкой к персонажу, чату и стилю, сила и information extracted, статусы моделей, кэш кодировок в браузере и у плагина, `/nai-vibes`.
- Окно прогресса: превью шагов на плагине, оценка по шагам без него, одноразовая подсказка.
- Схема настроек v5.
- Тесты: 323 (было 289). Покрытие `domain` — 98,8%.

### Исправлено

- Самодельные попапы (меню инструментов, лайтбокс) закрываются через `completeCancelled()`, ожидание попапа ST завершается.
- `fitArea` больше не теряет шаг по одной из сторон при ужатии до 1 Мп.

### Изменено относительно ТЗ

- 7 Director Tools, ZIP разбирается в браузере (RECON П-41); результат для медиа сообщения — новый элемент галереи сообщения (П-42).
- «Сохранить оригинал» — наложение по маске в браузере (П-43); аутпейнт и Enhance в «только бесплатных» ужимаются до 1 Мп (П-44, П-45).
- Два уровня кэша вайбов (П-46); вайбы V5 под фиче-флагом (П-47); функции Фазы 5 требуют плагин 0.2.0 (П-48).
- Платные критерии (кодирование вайба, апскейл, удаление фона) проверены на моках (П-49).

## [phase-2] — 2026-10-02

Паритет со встроенным Image Generation: после замены встроенное можно выключить без потерь. Таблица соответствия — `docs/PARITY.md`.

### Добавлено

- `domain`:
  - режимы встроенного с теми же числовыми id: персонаж, пользователь, сцена, сырое и последнее сообщение, лицо, свободный, фон, мультимодальные, свободный с LLM, а также шаблоны TOOL/MESSAGE;
  - выбор режима по триггеру, регулярка интерактивного режима, правила префикса персонажа и размеров кадра (`snap`);
  - сборка промпта: префикс с `{prompt}`, суффикс, промпт персонажа, `char` в свободном режиме, чистка ответа LLM;
  - правила автогенерации и бюджет Anlas для неё (0 в режиме «только бесплатные»).
- Пайплайн генерации из чата: промпт через LLM (`generateQuietPrompt`) или мультимодальную подпись, окно правки, событие `SD_PROMPT_PROCESSING`, сохранение в `/user/images`, сообщение-результат с видимостью по инициатору, свайпы картинки, фон чата.
- Слэш-команды:
  - `/nai` (`/nai-imagine`) и `/nai-style` — всегда;
  - после замены — `/imagine` (`/sd`, `/img`, `/image`), `/imagine-style`, `/imagine-source`;
  - все аргументы встроенного (параметры SD WebUI/ComfyUI принимаются и игнорируются) и аргументы NovelAI;
  - описания для автодополнения на ru/en.
- Точки UI: пункт в меню-палочке, кнопка генерации у каждого сообщения, overswipe, пункты «портрет» и «лицо» в меню карточки персонажа.
- Интеграция с LLM: интерактивный режим (`generate_interceptor`), инструмент `GenerateImage` с паузой между вызовами, макросы `{{charPrefix}}` / `{{charNegativePrefix}}`.
- Автогенерация: каждые N сообщений, по ключевым словам, по смене сцены; паузы по сообщениям и секундам. Цена проверяется до запроса к LLM.
- Промпты персонажей: локально и в карточке (`data.extensions.nai_studio`). Поле встроенного `sd_character_prompt` читается как запасной источник.
- Миграция из встроенного: один раз, с отчётом, без затирания своих настроек. Переносит стили и промпты персонажей из настроек и всех карточек.
- Замена встроенного: отключение и возврат с подтверждением, баннер в панели.
- Панель: вкладки «Генерация», «Промпты», «Чат», «Замена встроенного». Поля обновляются, когда настройки меняются снаружи (команды, миграция).
- Пересчёт транспорта и баланса при изменении ключа NovelAI в ST.
- Настройки: схема v2 (`prompts`, `modes`, `chat`, `auto`, `takeover`) с миграцией из v1.
- Тесты: 233 штуки (было 160). Новые — режимы, сборка промпта, автогенерация, миграция из встроенного, разбор аргументов команд, промпты персонажей, схема v2, динамические ключи i18n. Покрытие `domain` — 98%.
- `npm run format:check` в CI.
- `docs/PARITY.md`, `docs/reports/phase-2.md`, раздел «Замена встроенного» в `docs/DEPLOY.md`.

### Изменено относительно ТЗ и встроенного

- Стоковые значения `default/content/settings.json` миграция считает дефолтами и не переносит (RECON П-26).
- Текст сообщения подставляется через `substituteParamsExtended`: позиционная форма `substituteParams` в 1.19 не переопределяет `{{char}}` (П-27).
- Из ответа LLM удаляются служебные токены `<|…>` (П-29).
- Апскейл (`hr_scale`, `/sd scale=`) перенесён в Фазу 5 решением пользователя (П-30).

## [phase-1] — 2026-10-02

Ядро: одна картинка доходит до чата по обоим транспортам, и видно, что ушло в NovelAI и сколько это стоило.

### Добавлено

- Каркас: TypeScript 5 + Vite 8 (library mode, единый ESM-бандл `dist/index.js`, коммитится), vitest 5, ESLint 10 с правилами границ слоёв и запретом хардкода UI-строк, Prettier, `global.d.ts`, GitHub Actions CI, лицензия AGPL-3.0.
- `manifest.json`: `minimum_client_version: 1.19.0`, хуки `activate/install/update/delete/clean/enable/disable`, i18n `ru-ru`/`en-us`.
- `domain`:
  - реестр моделей (V5 Full/Curated, V4.5, V4, Anime V3, Furry V3);
  - матрица возможностей по RECON §3.4: V5 до 32 персонажей, Vibe и Precise Reference для V5 закрыты фиче-флагами;
  - payload-билдер V3/V4/V4.5/V5 с санитайзом (каждое удалённое поле с причиной), UC-пресеты и теги качества как в веб-клиенте;
  - raw-override (deep-merge после санитайза);
  - калькулятор Anlas по формуле веб-клиента: бесплатный сэмпл Opus, лимит V5 (`usage.isNegative`), режим «только бесплатные» с зажимом шагов, размера и числа картинок.
- `transport`: серверный плагин и штатный эндпоинт ST; автовыбор с деградацией и ручное переключение. Для штатного эндпоинта показывается точное тело, которое ST отправит в NovelAI, и список того, что потеряется.
- Серверный плагин `server/` (`/api/plugins/nai-studio`):
  - эндпоинты `/health`, `/generate`, `/subscription`;
  - токен читается из секретов ST или из `config.json`, в ответы и ошибки не попадает;
  - очередь с конкурентностью 1; ретраи на 429 всегда, на 5xx — только для бесплатных запросов; отмена при отключении клиента, таймаут;
  - HTTP 401 никогда не отдаётся (совместимость с basic auth).
- `core`: настройки со `schemaVersion`, миграциями и бэкапом в IndexedDB перед миграцией; логгер; i18n с английским fallback в бандле; карта ошибок на два языка с действием для каждой ошибки.
- UI: панель генерации в Extensions, инспектор payload (копирование JSON, удалённые поля, подсветка override, потери транспорта), вывод картинки в чат через `/api/images/upload` и `extra.media`.
- Тесты: 160 штук.
  - Snapshot-тесты билдера против эталонов `docs/captures` (структурное сравнение, решение П-9).
  - Тесты санитайза, цены, миграций, i18n (синхронность ключей, запрет кириллицы в коде, наличие динамических ключей), транспортов.
  - Интеграционные тесты плагина против мок-сервера NovelAI.
  - Покрытие `domain` — 97%.
- `npm run deploy:local`, `install-server.ps1` / `install-server.sh`, `docs/DEPLOY.md`, `README.md`.
- `docs/reports/phase-1.md`: результаты приёмки. Сверка стоимости на трёх платных конфигурациях совпала точно (8/8, 12/12, 10/10 Anlas).

### Изменено относительно ТЗ (решения Фазы 0)

- CORS-прокси как транспорт не реализован (П-3).
- Распаковки ZIP на клиенте нет: плагин запрашивает у NovelAI JSON (`Accept: application/json`), штатный эндпоинт сам отдаёт base64 (П-4).
